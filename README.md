# 환율 ATM

원화를 넣으면 오늘 환율로 바꿔서 외화가 나오는 **ATM 시뮬레이션**이에요. 환율을 확인하는 일을 지루한 숫자 표가 아니라 직접 해보는 경험으로 바꾸는 게 목표예요. 타깃은 트렌디한 2030 세대이고, 같은 사람이 일주일 꾸준히 다시 들어오는지를 핵심 지표로 봐요.

> 시뮬레이션이에요. 실제 환전이 아니에요. 결제, 계좌, 현금 입출금은 없어요.

## 실행 방법

설치할 것이 없어요. `index.html`을 브라우저로 열면 바로 동작해요.

```bash
open index.html
```

- 환율을 불러오려면 인터넷 연결이 필요해요.
- 서버, 빌드, 패키지 설치는 필요 없어요.

## 사용 방법

1. 오른쪽 위 칩에서 받을 통화(USD, JPY, EUR)를 골라요.
2. 키패드(또는 키보드 숫자)로 넣을 금액을 입력해요. 1,000원부터 1,000,000원까지 가능해요.
3. 지폐를 투입구로 끌어넣거나 탭해요. 화면의 `환전하기` 버튼을 눌러도 같아요.
4. 외화 지폐가 아래 배출구로 나오면 `가져가기`를 눌러요.
5. 결과 시트에서 받은 금액, 적용 환율, 기준일, 어제 대비 등락을 확인해요. `다시 하기`로 처음부터 다시 할 수 있어요.

연출 중에는 언제든 `건너뛰기`로 결과로 갈 수 있어요.

## 재미 요소

| 요소 | 내용 |
|---|---|
| 지폐 투입 | 지폐를 투입구로 끌어넣거나 탭해요. 기기가 흔들리고 진동이 와요. |
| 현금 배출 | 외화 지폐가 한 장씩 나오고, 직접 가져가야 결과가 열려요. |
| 숫자 롤링 | 받은 금액이 0에서 올라가며 멈춰요. |
| 등락 리액션 | 어제보다 오르면 🚀(초록), 내리면 😢(빨강), 같으면 😐이에요. |
| 연속 방문 스탬프 | 방문할 때마다 도장이 찍혀요. 7일 연속이면 축하 효과가 나와요. |
| 키패드 | 누르는 느낌의 눌림 효과와 진동이 있어요. (진동은 지원하는 기기만) |

## 환율 데이터

[Frankfurter](https://frankfurter.dev) API(v2)를 써요. 키가 필요 없고 CORS가 열려 있어서 HTML에서 바로 호출해요.

```
GET https://api.frankfurter.dev/v2/rates?base=USD&quotes=KRW
GET https://api.frankfurter.dev/v2/rates?base=USD&quotes=KRW&date=YYYY-MM-DD   # 전일 환율
```

응답은 배열이에요.

```json
[{"date":"2026-10-21","base":"USD","quote":"KRW","rate":1329.09}]
```

- **환산 방식:** 외화를 base로 조회해서 `원화 ÷ rate`로 계산해요. `base=KRW`로 조회하면 `rate`가 소수점 5자리로 반올림되어(USD 0.00075) 오차가 생기기 때문이에요.
- **기준일:** 응답의 `date`를 그대로 보여줘요. 주말이나 공휴일에는 직전 영업일 값이 와요.
- **등락:** 전일 환율의 `date`가 오늘 값보다 이전일 때만 계산해요.
- **실패 시:** 오류 화면과 `다시 불러오기` 버튼을 보여줘요. 이전에 불러온 환율이 있으면 그 값으로 대신하고 "저장된 환율이에요"라고 표시해요.

## 저장하는 데이터

브라우저 `localStorage`에만 저장하고, 서버로 보내지 않아요.

| 키 | 내용 |
|---|---|
| `fxatm.visits` | 방문한 날짜 목록(최근 30일) |
| `fxatm.rates` | 마지막으로 불러온 환율(실패 시 대체용) |

개인정보는 저장하지 않아요.

## 구현 원칙

- **HTML만 사용해요.** 프레임워크, 빌드 도구, 외부 라이브러리, 폰트 CDN이 없어요. 외부 통신은 환율 `fetch`뿐이에요.
- **디자인은 `DESIGN.md`(토스)를 따라요.** ATM 기기 외형은 참고 이미지를 CSS로 직접 그렸어요.
- **접근성:** 키보드 포커스 표시, `prefers-reduced-motion` 대응, 44px 이상의 터치 영역, 모바일 375px 기준 레이아웃을 지켜요.
- **환전 방향:** 원화 → 외화 한 방향만 지원해요.

## 지원 범위와 한계

- 통화는 USD, JPY, EUR 세 가지예요. JPY는 100엔 단위로 환율을 보여줘요.
- 수수료와 스프레드 없이 매매기준율 그대로 계산해요.
- 결과 공유 기능은 아직 없어요.
- 환율 요청에 타임아웃이 없어서, 응답이 오지 않으면 "불러오는 중"이 오래 이어질 수 있어요.
- 화면 오른쪽 위 날짜는 기기 시계 기준이라 환율 기준일과 다를 수 있어요.
- 명도 대비 4.5:1은 일부 색만 맞춰뒀고 도구로 전체를 검사하지는 않았어요.
